# Contract: 通知

| 通知 | チャンネル（重要度） | 本文 | ボタン | 押すと |
|---|---|---|---|---|
| 常駐 | `connection`（MIN、音なし） | 「Gateway につながっています」/「つなぎ直しています」 | なし | アプリを開く |
| 応答 | `replies-<agentId>`（DEFAULT、グループ「応答」） | タイトル = 会話名、サブ = エージェント名、本文 = 応答の冒頭 | なし | その会話を開く |
| 承認待ち | `approvals`（HIGH） | タイトル = 「承認を求めています」・エージェント名、本文（広げる）= コマンドの全文・対象・警告・会話名 | 1 回だけ許可・常に許可・拒否（ロック解除が要る） | アプリの承認の表示 |
| 自動化の失敗 | `automation-failures`（DEFAULT） | タイトル = 自動化の名前、本文 = 失敗の 1 行 | なし | 自動化の詳細 |
| テスト | 既定のエージェントの `replies-<agentId>`（エージェントが無ければ `replies-test`） | 応答と同じ形。タイトル = 「通知のテスト」、サブ = エージェント名、大きなアイコン = エージェントの顔 | なし | アプリを開く |

- 通知の id: 常駐 = 固定、応答 = 会話の key のハッシュ、承認 = `ApprovalKey` のハッシュ、自動化 = 自動化の id のハッシュ
- ロック画面: 端末の設定に従う（アプリの項目は 2026-11-26 に削除）。端末が伏せるときのため、公開版（タイトルだけ「新しい応答」など）を常に付ける
- 文言は `values/strings.xml`（日本語だけ）。チャンネル名・説明も同じ
