# Quickstart: エージェントの設定を確かめる

**前提**: Debug 版（日本語）をマスターの Gateway につないだ端末。エージェントが 2 つ以上ある。
手順の詳細は [contracts/ui.md](./contracts/ui.md)、呼び出しは [contracts/gateway-rpc.md](./contracts/gateway-rpc.md)。

## ビルドと単体テスト

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

期待: すべて通る。`FilesRepositoryTest`（agents.files の往復・衝突）、`OpenedFileControllerTest`、`SkillsTest`（状態の決め方・並び順）、
`AgentSettingsViewModelTest`（先に見せる切り替えと失敗時の戻し）を含む。002 の `FilesViewModelTest` が切り出しのあとも通る。

## 実機での確認

| # | 操作 | 期待 | spec |
|---|---|---|---|
| 1 | サイドパネルを開き、名前の横の編集のアイコンを押す | 選んでいるエージェントの設定が右から重なって開き、「概要」が出る | US1-1、FR-001 |
| 2 | 会話の応答のアバターを押す | そのエージェントの設定が開く | US1-2、FR-002 |
| 3 | 概要の数・モデルを Web UI と見比べる | 一致する | US2 |
| 4 | 「ファイル」→ AGENTS.md → 編集 → 1 行足して保存 | Snackbar で保存を示す。Gateway のファイルが変わる | US1-5 |
| 5 | AGENTS.md を開いたまま、PC で同じファイルを書き換えてから保存 | 衝突のダイアログ。上書き・読み直しのどちらも動く | US1-6、SC-003 |
| 6 | 未作成のファイル（例: USER.md）を作って保存 | ファイルができる | US1-7 |
| 7 | 編集の途中でアプリを強制終了して開き直す | 下書きが戻る | US1-8、SC-004 |
| 8 | 「スキル」で要件が足りないスキルを押す | 足りないものと SKILL.md がシートで読める | US3-2・3 |
| 9 | スキルを 1 つ無効にし、Web UI で確かめ、「元に戻す」 | 押した瞬間に切り替わる。Web UI でも無効。元に戻る | US3-4、SC-006 |
| 10 | 機内モードでスキルを切り替える | 元の状態に戻り、理由が出る | US3-4 |
| 11 | 設定を開いたまま、パネルで別のエージェントを選ぶ | 開いている設定は元のエージェントのまま | Edge |
| 12 | 予測型「戻る」を途中で止める・タブを連打する | 飛び・ちらつきがない（アニメーター 5x でも） | 憲章 I |
