# Quickstart: アプリのショートカット

## 単体テスト

```sh
./gradlew testDebugUnitTest --tests '*core.shortcut*' --tests '*core.notify.OpenIntents*'
```

- `ShortcutReconcileTest`: アクティブ → そのまま、アーカイブ → 外して無効、アーカイブが戻る → 戻す、どこにも無い → 枠ごと外す、
  一覧が読み込み中・失敗のエージェントは判定しない、エージェントが消えたら外す（エージェントの一覧が失敗・空なら外さない）、`Home` は判定しない
- `ShortcutLabelTest`: `customLabel` が先、無ければ エージェント名 / フォルダの最後の名前 / セッション名
- `ShortcutSettingsJsonTest`: 3 種類の行き先が JSON を行き来する、知らない項目は読み飛ばす
- `OpenIntentsTest`: `session` / `new_chat`（`CWD` あり・なし）/ `automation` / `approvals` を書いて読み戻す、足りない extras は `null`
