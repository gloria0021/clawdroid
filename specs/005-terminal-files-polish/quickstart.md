# Quickstart: ターミナルとファイルの磨き込み

## 前提

- `operator.admin` で接続した Pixel（ターミナルとファイルの操作に必要）。作業フォルダのある会話を 1 つ
- 外付けキーボード（Bluetooth か USB）。無ければ US2 の外付けの確認は飛ばす
- `./gradlew testDebugUnitTest assembleDebug` が通り、`adb install -r` で入れてある

## 単体テスト

```sh
./gradlew testDebugUnitTest --tests '*TerminalBannerTest' --tests '*FileTreeStateTest' --tests '*LineIndexTest' --tests '*FileOpsRepositoryTest' --tests '*EditHistoryTest'
```

- `TerminalBannerTest`: 19 / 20 / 46 / 47 / 70 / 71 / 200 桁で、形が `BannerShape` の表どおりで、どの行も桁数を超えない
- `FileTreeStateTest`: 展開・折りたたみ・読み込み中・失敗の行、深さ 9 以上で字下げが増えない、`expanded` が保存と復元を越える
- `LineIndexTest`: LF / CRLF / CR、空のファイル、最後の改行の有無で行番号が合う
- `FileOpsRepositoryTest`: 偽の `terminal.data` で、エコーされたコマンド行を印と取り違えない、終了コード 0〜5 と時間切れの対応、`'` を含む名前のクォート、名前の検証の各エラー
- `EditHistoryTest`（使う場合）: まとめ・上限・やり直しの破棄
