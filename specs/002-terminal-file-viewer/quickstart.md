# Quickstart: ターミナルとファイルビューア の確かめ方

前提: Pixel を adb でつなぐ（`~/Dev/Android/Sdk/platform-tools/adb`）。Gateway は 2026.11.6、この端末の接続に `operator.admin` がある。

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 1. 辿って読む（US1）
1. 作業フォルダのある会話を開き、タイトルバーのフォルダのアイコンを押す → 一覧（フォルダが先）
2. フォルダを 2 段降りてコードのファイルを開く → 等幅・色分け
3. 画像を開く → 全画面、つまんで拡大
4. 戻るで 1 段ずつ戻る。根で戻ると会話へ（予測型「戻る」を途中で止めても崩れない）
5. 上部の切り替えで「ワークスペース」→ 同じように辿れ、編集の操作は出ない

## 2. 直して保存（US2）
1. テキストのファイルで編集 → 1 行直す → 保存 → Snackbar。PC で中身が変わっている
2. 編集中にアプリを強制終了 → 開き直して同じファイル → 変更が残っている
3. 開いたあと PC で同じファイルを書き換え → 保存 → 衝突のダイアログ。「上書き」「読み直し」の両方を試す
4. 保存せず戻る → 捨てるかの確認

## 3. ダウンロード（US3）
1. ファイルを開いてダウンロード → Snackbar の「開く」で開ける。端末の Download に同じ内容
2. 同じファイルをもう一度 → 別名で保存される

## 4. ターミナル（US4）
1. 会話からターミナルを開く → `pwd` が会話の作業フォルダ、`ls` が表示される
2. 特殊キーの行で Ctrl → c（`sleep 100` を止める）、Tab 補完、↑で履歴
3. 端末を回転 → `tput cols` が変わる、表示が崩れない
4. ホームに戻って 1 分後に戻る → 続きが出る（離れていたあいだの出力も）
5. `exit` → 終了の表示と開き直し
6. PC の Control UI で同じ PTY を attach → こちらに「別の場所で開かれた」と取り戻す操作

## 5. 共通
- アニメーター再生時間スケール 5x で、フォルダの入れ替え・ファイルを開く動きにちらつきが無い
- 文字 200% で一覧・特殊キーの行が切れない
- `grep -rn "Color(0x\|\.sp\b" app/src/main` でテーマ・Spacing 以外に該当なし
