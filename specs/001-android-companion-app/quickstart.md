# Quickstart: 検証の手順

**Plan**: [plan.md](./plan.md)

実装が spec を満たすかを確かめる手順。実装のコードは書かない。

## 前提

- 開発用 PC: Android SDK（`~/Dev/Android/Sdk`）、JDK 21
- 実機: Android 13 以上（中位機種を 1 台含める。SC-003）
- OpenClaw Gateway 2026.11.6 が動いていて、実機から Tailscale か LAN で到達できる
- Gateway のトークン（`gateway.auth.token`）を手元に用意する

## ビルドと起動

```sh
./gradlew :app:assembleDebug
./gradlew :app:installDebug
./gradlew testDebugUnitTest
```

## 検証 1: 初回接続と承認（US1、FR-001・004）

1. アプリを初めて開く → 接続画面が出る
2. 誤ったトークンで接続 → 「認証が拒否された」と出て、入力は残る
3. 到達できないアドレスで接続 → 「到達できない」と出る
4. 正しいトークンで接続 → 「承認待ち」になる
5. Control UI の Devices か `openclaw devices approve` で承認 → 自動で接続が続き、セッション一覧が出る
6. アプリを終了して開き直す → 接続画面は出ない

## 検証 2: エージェントの切り替えと会話（US1、SC-003・004・005）

1. サイドバーでタブを切り替え、スワイプでも切り替える → 一覧がエージェントごとに替わる
2. 切り替えの途中で別のタブを連打する → 飛び・ちらつき・操作不能が起きない
3. 開発者向けオプションのアニメーター再生時間スケールを 5x にして、1・2 を繰り返す
4. メッセージを送る → 応答が届いた分から順に出る。停止で止まる
5. 1,000 件を超える会話をスクロールする → カクつかない
6. 予測型「戻る」を途中で止める → 前の画面がのぞき、離すと元に戻る

## 検証 3: 通知（US2、FR-100〜107、SC-010・011）

1. 別の端末（Control UI）から、エージェント A と B に依頼する。Clawdroid はホームに戻しておく
2. 応答が完了すると、エージェントごとにまとまった、内容付きの通知が出る（5 秒以内）
3. 通知の返信欄から送る → アプリを開かずに会話に届き、通知に結果が出る
4. Android の設定でエージェント B のチャンネルをオフ → B の通知だけが止まる
5. その会話を画面で開いているときは通知が出ない
6. 機内モードで 5 分待ってから戻す → 切れていたあいだに完了した応答がまとめて通知される

## 検証 4: 電池の計測（SC-013）

```sh
adb shell dumpsys batterystats --reset
# 常駐オン、画面オフで 24 時間待ち受け（Wi-Fi の日とモバイル回線の日を分ける）
adb shell dumpsys batterystats > batterystats.log
```

- アプリ（uid）の消費が端末全体の 3% 以下か。超えたら research R6 の追加策を検討する
- 同時に、Gateway 側の `tick` と ping の間隔（25 秒・30 秒）が版で変わっていないかを確かめる

## 検証 5: セッション作成とフォルダ（US3）

1. 新規チャット → フォルダの選択でホストのフォルダを辿って選ぶ
2. 最初のメッセージを送る → ヘッダにフォルダ名が出て、エージェントがそのフォルダで作業する

## 検証 6: モデル・エフォート・使用量（US4、SC-006）

1. モデルとエフォートを切り替える → 次の応答に反映される
2. エフォートの選択肢がないモデルでは、エフォートの選択が消える
3. 詳細シートの値（コンテキスト・トークン・使用枠）が、同時刻の Control UI と一致する

## 検証 7: ファイル（US5）

1. 作業フォルダのファイルを開き、1 行直して保存 → Gateway 上で変わっている
2. 同じファイルを Control UI で先に変えてから保存 → 衝突が示される
3. ファイルをダウンロード → 端末のダウンロードに保存される

## 検証 8: ターミナル（US6）

1. ターミナルで `pwd`、`ls` → 結果が出る。Ctrl+C・Tab・矢印が送れる
2. アプリを離れて 1 分後に戻る → 同じターミナルの続きが出る

## 検証 9: 再起動（US7、SC-007）

1. 再起動ボタン → 確認ダイアログ → 再起動中 → 再接続中 → 接続済み（60 秒以内）
2. ボタンを連打しても、指示は 1 回だけ

## 検証 10: 自動化（US8、SC-012）

1. 新規作成（cron 式 `0 9 * * *`、Asia/Tokyo）→ 次の実行予定が出る → 保存
2. 今すぐ実行 → 結果が一覧に出て、実行で生まれた会話を開ける
3. 無効にする → 次の実行予定が消える。削除は確認を経る

## 検証 11: テーマと見た目（US9、SC-009）

1. OpenClaw（赤）・モダン（モノクロ）・ダイナミック（壁紙）・カスタム（白と灰色も試す）を切り替える
2. ガラス / ぼかしを切り替える
3. ライト / ダーク × スマホ / タブレット × 文字 100% / 200% で崩れがない
4. `grep -rn "Color(0x\|\.sp\b" app/src/main` で、テーマと Spacing 以外に直書きがない
