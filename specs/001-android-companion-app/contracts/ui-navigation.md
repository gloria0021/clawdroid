# Contract: 画面と遷移

見た目と動きの細則は `AGENTS.md` を正とする。ここは画面の構成と遷移の約束だけを書く。

## 画面（Navigation 3 の行き先）

| 行き先 | 内容 | 主なストーリー |
|---|---|---|
| `Connect` | 接続先・ゲートウェイトークンの入力、承認待ちの表示 | US1 |
| `Chat(agentId, sessionKey?)` | 会話（`sessionKey` が無ければ新規） | US1・US3・US4 |
| `Files(sessionKey, agentId)` | ファイルの一覧 → 内容の表示・編集（中のページはファイルビューアの中で重ねる） | US5 |
| `Terminal(sessionKey?, agentId?, cwd?)` | ターミナル | US6 |
| `Automations(agentId)` | 選択中のエージェントの自動化の一覧 | US8 |
| `AutomationDetail(jobId)` | 自動化の詳細（設定 / 実行履歴）。項目の編集はシート | US8 |
| `Settings` | 接続・再起動・エージェント・表示（1 画面に縦に並べる） | US7・US9 |
| `AgentLayout` | サイドパネルに出すエージェントの並びと表示 | US1 |

- サイドバーは画面ではなく `Chat` の一部（スマホは `ModalNavigationDrawer` の中身を全画面にする。大画面の list-detail は未実装）
- 補助の表示（セッションのシート＝モデル・エフォート・権限・使用量、フォルダの選択、並行開発、変更量、質問、承認、項目の編集）は `ModalBottomSheet`。中身の多い詳細（自動化の詳細）は新しい画面でよい（AGENTS.md 2.7）
- 確認（再起動・削除・編集の破棄・接続情報の削除）は `AlertDialog`

## サイドパネル（2026-11-23 マスター指定で変更）

```text
┌───────────────────────────┐
│ [エージェントの顔の画像。下へ溶ける]   (✕) │ ← 頭の看板（ステータスバーの裏まで）
│ 開発創造層- Moonshot          │ ← 名前（headlineSmall、2 行まで）
│ ⌂ ホーム  ⏱ 自動化       (✎) ⚙ │ ← 操作の行（新しいセッション・設定はアイコンだけ）
│ 📌 ピン留めしたセッション       │
│ セッション履歴      [更新順/フォルダ別] │
│  アクティブ · n                 │
│   タイトル（1 行）  時刻  目印   │ ← フォルダ別はフォルダを親にしたツリー
│  アーカイブ済み · n             │
│      ( 🧑 | 🧑 | 🧑 | 🧑 )  ← 下部に浮くピル型タブ（最大 4 体） │
└───────────────────────────┘
```

- 左端からのスワイプで開き、画面いっぱいまで広がる（Gemini 型）。会話の画面にサイドパネルを開くボタンは置かない
- エージェントの切り替えはタブを押すだけ。顔・名前・ホーム・自動化・履歴が一緒にフェードで入れ替わる。横のスワイプはパネルを閉じる
- 履歴の行の長押し: 名前を変更・並行開発を開始・アーカイブ（解除）・削除。ピン留めの行の長押し: ピンを外す
- 再起動のボタンは設定にだけ置く

## 会話の画面

- 帯（TopAppBar）は置かない。右上に「Clawdroid」のガラスのピルだけを浮かせ、押すとセッションのメニュー:
  名前を変更・ピン留め、区切って ファイル・ターミナル・並行開発を開始・変更量（合計の +/− を添える）。新しいチャットではファイル・ターミナルだけ
- 上端は会話を背景色へ溶かし、ステータスバーとピルを読みやすくする（`Modifier.statusBarFade()`）
- ヘッダにセッション名・作業フォルダ名は出さない（新しいチャットの空の状態だけ、作業フォルダのチップを出す）
- 下部に浮く入力ピル: 上に入力、下の行に 添付 ｜ モデルのピル（押すとセッションのシート）｜ マイク／送信（生成中は停止）。ピルの上に待ちの行・質問の行・補完の候補
- 最下部へ戻るボタンは、上へスクロールしているときだけ出す

## 通知から開く

- 通知を開く → `Chat(agentId, sessionKey)` の該当するメッセージの位置
- 承認待ちの通知を開く → 同じ会話で承認のシートを開く
- 自動化の失敗の通知を開く → `Automations` の該当する実行
