# Contract: 画面と遷移

見た目と動きの細則は `AGENTS.md` を正とする。ここは画面の構成と遷移の約束だけを書く。

## 画面（Navigation 3 の行き先）

| 行き先 | 内容 | 主なストーリー |
|---|---|---|
| `Connect` | 接続先・ゲートウェイトークンの入力、承認待ちの表示 | US1 |
| `Chat(agentId, sessionKey?)` | 会話（`sessionKey` が無ければ新規） | US1・US3・US4 |
| `Files(sessionKey, path)` | ファイルの一覧 → 内容の表示・編集 | US5 |
| `Terminal(sessionKey?)` | ターミナル | US6 |
| `Automations(agentId?)` | 自動化の一覧 → 詳細・編集・実行履歴 | US8 |
| `Settings` | 接続・通知・テーマ・言語（1 画面に縦に並べる） | US7・US9 |

- サイドバーは画面ではなく `Chat` の一部（スマホは `ModalNavigationDrawer`、大画面は list-detail の list 側）
- 補助の表示（モデルの選択、使用量の詳細、フォルダの選択、メッセージの操作、自動化の編集）は `ModalBottomSheet`。新しい画面にしない（AGENTS.md 2.7）
- 確認（再起動・削除・編集の破棄）は `AlertDialog`

## サイドバー

```text
┌───────────────────────────┐
│ [Moonshot][Wordsmith][…]   │ ← エージェントのタブ（ガラスの面）
├───────────────────────────┤
│ セッション一覧（Pager の 1 ページ＝1 エージェント）│
│  ・タイトル（2 行まで）/ 更新時刻 / 未読・実行中の目印 │
├───────────────────────────┤
│ 自動化 / ターミナル / 設定   │ ← 下部（ListItem）
└───────────────────────────┘
```

- タブのタップとページのスワイプは同じ位置の値に追従する。途中で別のタブを押しても動きがつながる
- 再起動のボタンは 設定 と ⋮ メニューの両方に置く（ワンボタンの要件。FR-070）

## 会話の画面

- 上部に浮くボタン: 左 = サイドバー、右 = 新規チャット・⋮（ファイル・ターミナル・使用量の詳細・再起動）。TopAppBar のアイコンは最大 2 つ（AGENTS.md 2.6）
- ヘッダの中央: セッション名と作業フォルダ名（`titleMedium` / `labelMedium`）
- 下部に浮く入力ピル: 添付 ｜ 入力欄 ｜ マイク／送信（生成中は停止）。ピルの上にモデルとエフォートの選択
- 最下部へ戻るボタンは、上へスクロールして新しい応答が届いたときだけ出す

## 通知から開く

- 通知を開く → `Chat(agentId, sessionKey)` の該当するメッセージの位置
- 承認待ちの通知を開く → 同じ会話で承認のシートを開く
- 自動化の失敗の通知を開く → `Automations` の該当する実行
